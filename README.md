# Position Sizer RR — MT5 分仓止盈版

当前版本：**RR 1.20**（MT5 文件版本 `3.160`）。图表显示每笔持仓的各个 TP、实际目标价格、平仓比例和 BE；“分仓止盈”页可以选择已有持仓并修改未触发目标。保留最多 20 个目标、独立 BE 及初始化/残框修复。

基于你提供的 EarnForex Position Sizer 3.14 中文源码扩展。保留仓位计算、风险百分比、图表入场/止损线和下单面板，增加多目标自动退出。原参考目录没有修改。

这是**手动选择入场、EA 自动管理退出**的版本，不会自行寻找买卖信号或自动开第一笔仓。

## 在页面设置止盈

点击面板顶部的 **分仓止盈**。默认是 2R 平 50% 并 BE、5R 平剩余 50%。

1. 点击“添加目标”，填写目标 R 和平仓百分比；可删除不需要的行。每页显示 5 行，多于 5 行时翻页编辑。
2. 在希望上保护的目标行勾选 **BE**。允许多行勾选；价格达到任意勾选目标就请求将止损移至开仓价（加输入参数中的保本偏移）。若止损已更有利，不会移回较差位置。
3. 只想上保护、不想减仓时，设置 **0% 并勾选 BE**。
4. R 必须为正数并严格递增，平仓百分比合计必须是 **100%**。最后一行执行剩余全平，处理手数取整后的余量。
5. 在 **新仓方案** 模式点击 **保存新仓方案**，仅用于后续新仓。有本 EA 的未成交订单或尚未完成记录的新仓时，需要先等待订单处理完成再保存。未保存草稿不影响执行。

## 在持仓过程中修改

1. 打开 **分仓止盈**，选择 **持仓**，多笔仓位时切换到需要修改的持仓编号。
2. 页面显示该仓位的真实成交价、冻结的 1R 和剩余手数。修改尚未触发的目标 R、初始仓位百分比、BE，也可以增加或删除未触发目标。每行显示目标价。
3. 点击 **应用到该持仓** 才保存；只修改当前选中的仓位，不会改变其他仓位或新仓默认方案。图表线显示已保存方案，编辑框中的目标价是草稿预览。
4. 已触发的行锁定，不可以修改或删除；原来的初始手数、1R、减仓进度和已经触发的 BE 都保留。例如 2R 已平 50% 后，后面的 5R/50% 可改为 6R/50%，不会再平一次前 50%。
5. 编辑期间若已触发新目标或其他图表已修改方案，保存会拒绝旧草稿，需要重新载入。平仓等待确认、管理暂停或已触发减仓尚未完成时也暂不能保存。
6. 新目标必须位于当前可平仓报价的盈利方向前方至少一个最小跳动，防止保存后立即补平已经越过的目标。手动减仓计入累计，后续减仓须满足券商最小手数。

最终 TP 保存到方案后由管理循环向服务器同步。页面和图线会区分 **最终 TP 待同步** 与 **服务器 TP**；算法交易关闭、连接中断或券商拒绝期间，旧服务器 TP 仍可能有效。没有收到服务器确认前，不应把草稿或新目标线当作已修改成功的服务器订单。

RR 1.10 建立的多目标持仓记录可以直接编辑；RR 1.01 的旧两阶段记录仅支持显示，继续按旧执行语义管理。没有 RR 记录的旧仓不会通过编辑页面自动接管。

## 图表上的目标线

每条持仓目标线标注类似 `#158809575 | TP1 2R | 4326.38 | 平 50% + BE`。已触发目标保留并显示灰色及“已触发”；触发表示条件已经锁定，不代表平仓和 BE 两个请求均已成功。有管理中的仓位时，目标按真实成交价和原始止损距离计算，不跟随左侧新单预览价。

没有可显示的 RR 持仓时显示“新仓预览”；它随计算器变化。超出当前图表价格范围的目标保留水平线，并在边缘标出“图外”和价格。目标线只用于显示，请在分仓止盈页面修改。持仓关闭后对应线自动清除，卸载 EA 只清除本模块的目标标记，不删除手动画线。

到价判断与图线采用同一个合法最小跳动价。多单看 Bid、空单看 Ask；RR 1.20 修正了恰好到达目标价格时因浮点误差延后一跳的问题。

例如：

| 目标 | R 倍数 | 平仓比例 | BE |
|---|---:|---:|---|
| 1 | 1 | 0% | 勾选：只上保护 |
| 2 | 2 | 50% | 不勾选 |
| 3 | 3 | 25% | 可勾选 |
| 4 | 5 | 25% | 不勾选 |

**所有百分比按初始仓位计算**，不是按每次剩余仓位计算。方案保存在本图表的设置文件中，正常重启、切换周期后可恢复。更换图表属于独立方案。

## 首次加载的默认规则

以下四个目标相关输入仅在本图表尚无已保存方案时生成初始两行。已有保存方案时，请在“分仓止盈”页面编辑。

| 设置 | 默认值 | 含义 |
|---|---:|---|
| 启用分仓止盈 / `RR_Enable` | true | 使用本扩展管理退出 |
| 第一目标 / `RR_FirstTarget` | 2.0 | 到初始风险的 2 倍时减仓 |
| 平仓百分比 / `RR_ClosePercent` | 50.0 | 平掉**初始仓位**的 50%，不是每次平掉剩余的一半 |
| 最终目标 / `RR_FinalTarget` | 5.0 | 到 5R 平掉全部剩余仓位 |
| 第一目标保本 / `RR_MoveToBE` | true | 新方案第一目标到价即请求 BE；与平仓请求分别确认 |
| 保本额外点数 / `RR_BEOffsetPoints` | 0 | 0 = 实际开仓价；正数向盈利方向偏移，单位为该品种的 point |
| 平仓偏差 / `RR_DeviationPoints` | 20 | 市价平仓允许偏差，单位 point，实际处理取决于券商执行模式 |

`1R = |实际开仓价 − 初始止损价|`。成交后记录下来，不随止损移至 BE 或调整图表线而改变。

例如，多单开仓 3000、初始止损 2990、初始仓位 0.10 手：

1. 1R = 10 个价格单位。
2. Bid 到 3020：请求平 0.05 手，并请求把止损移到 3000；两项以交易服务器确认结果为准。
3. Bid 到 3050：平掉剩余 0.05 手。
4. 如果完成第 2 步后先回到 BE，则剩余仓位在保本止损退出，不再等待 5R。

空单方向相反，使用可实际平仓的 Ask 判断目标。若直接跳到最终目标，则直接全平，不先执行半仓和 BE。

这里的 R 是价格距离倍数。BE 默认是开仓价格，不包含手续费、隔夜费和成交滑点，因此不等于扣除成本后的净收益为零。两个目标均成交时，默认组合约为 **3.5R**，未扣成本。

## 安装和使用

1. 在 MT5 中选择“文件 → 打开数据文件夹”，进入 `MQL5\Experts`。
2. 新建 `PositionSizerRR` 文件夹，将本包 `mt5` 内文件放入。已有编译版时只放 `Position Sizer RR.ex5` 也可运行，图标已嵌入。
3. 在导航器刷新“EA 交易”，把 **Position Sizer RR** 加载到你准备交易的品种图表。
4. 在面板 **分仓止盈** 页添加和保存各目标；首次加载默认 2R/50%/BE、5R/50%。先用模拟账户验证券商执行情况。
5. 主选项页的止盈数量设为 **1**，交易页原有“Break-Even / 保本”和“Trailing Stop / 移动止损”均设为 **0**；保持应用 SL 和 TP。多个目标统一在 **分仓止盈** 页管理。
6. 默认专用 Magic Number 为 **2026092201**。不要与其他 EA 共用；持仓期间保持 Magic 和交易品种不变。
7. 正常在面板选择多空、拖动初始止损、设置风险比例或金额，确认仓位，再按原来的交易按钮下单。最终 TP 线自动按最终 R 计算。
8. 保持 MT5、图表上的 EA 和“算法交易”运行。第一阶段减仓与 BE 需要终端在线；成功提交到服务器的 SL 和最终 TP 在终端关闭后仍由服务器执行。

RR 模式要求图表品种就是下单品种，`TradeSymbol` 留空或与图表品种相同。同一品种和 Magic 使用一个 RR 实例。**新仓成交并完成首次记录时冻结方案、初始风险、BE 偏移**；已记录仓位继续使用其保存参数。存在本 EA 未成交订单或未捕获新仓时，页面禁止保存新方案。平仓偏差使用当前输入值。

面板设置独立保存到 `MQL5/Files/PSRR_Settings/`，默认图表对象前缀为 `PSRR_`，与原版设置隔离。

面板的“收益”和风险回报字段仍沿用原版**全仓在最终 TP 退出**的估算；例如会显示接近 5R，而不是分仓组合的 3.5R。实际分仓规则以 RR 参数为准。

## 执行细节

- 只管理**当前交易品种 + 当前面板 Magic** 匹配的新仓，以及本版本已保存记录的仓位。首次加载时已有、没有 RR 记录的仓位不会自动接管。EA 停用期间新开的仓位在重新加载时也属于未接管旧仓。
- 对冲账户按具体持仓票号减仓/改止损，可分别管理多张持仓。
- 净额/交易所账户每个品种只允许一笔独立入场。在该品种已有任何持仓或挂单时，RR 模式会阻止新入场。不要让其他策略同时操作同品种。检测到外部加仓、反转或均价变化后，暂停该仓位管理并记录日志；已有服务器 SL/TP 不会因此自动删除。
- 挂单实际成交后才建立 R 基准；同一入场单分次成交时，等待入场订单结束后确认实际总手数。
- 中间目标按累计百分比计算，再按券商步长向下取整。例如 0.03 手的 50%，在步长 0.01 时实际平 0.01 手，剩 0.02 手。下单前检查每一阶段的平仓量和余仓量，无法满足最小手数时拒绝下单。
- 已有仓位若因外部变化无法完成规定分仓，不擅自扩大减仓量，写日志并等待后续目标；已触发的 BE 独立重试。
- 已手动减少的仓位计入累计减仓量。达到第一目标时，只补足还需要减少的数量。
- BE 只会改善止损，不会把已移动到更有利价格的止损拉回开仓价。券商止损距离或冻结区不允许修改时继续重试；此期间旧止损仍有效，BE 尚未生效。
- 最终 TP 以实际成交价和初始止损为基准校正到合法 tick；第一目标由 EA 市价执行，实际成交价格可能有滑点。
- 本版本的市价平仓使用 FOK 或 IOC；品种若两者均不支持则停止自动市价分仓并记录日志。最终服务器 TP/SL 的执行不依赖此市价平仓模式。

## 重启恢复与异常

每笔仓位的初始风险、初始手数、冻结参数和阶段写入终端数据目录的 `MQL5\Files\PS_RR\<服务器标识_账户>\<持仓标识>.bin`。

正常重启或重新加载后，读取记录并核对成交历史；已经完成的第一阶段不会重复平仓。关闭前尚未成功设置 BE 的，会继续尝试设置。换电脑/换终端时，除 EA 文件外，还需迁移对应 `PS_RR` 状态目录。

为防止超时后重复平仓，程序先保存交易意图，再发出请求。若服务器回复不确定、成交记录未同步或记录文件损坏，程序会暂停该仓位的后续管理并在“专家”日志提示，等待确认或人工核对。**不能保证所有断线异常都会自动恢复。**不要通过删除状态文件强行重置；先核对终端持仓、交易历史和日志。不要在多个不同 MT5 终端上同时运行本 EA 管理同一账户的同一仓位。

原版 EA 不应同时管理同一批仓位；否则原版 BE/移动止损或人工操作可能与本扩展冲突。

升级前已由 RR 1.01 记录的仓位继续使用旧两阶段规则和旧日志格式（减仓确认后设 BE）。保存新仓默认方案不会覆盖已有仓位；编辑 RR 1.10/1.20 持仓需要明确选择该仓位并点击“应用到该持仓”。
