Position Sizer RR 1.20

本包已编译：0 errors / 0 warnings。可直接使用 mt5 文件夹内的 Position Sizer RR.ex5。

替换方法
1. 在 MT5 选择“文件 → 打开数据文件夹”。
2. 找到原来安装的 MQL5\Experts 下的 Position Sizer RR.ex5，先保留旧文件备份。
3. 用本包 mt5\Position Sizer RR.ex5 替换旧 EX5；源代码编译使用者请同时替换 mt5 文件夹中的源码与资源。
4. 在对应图表重新加载 EA，确认标题为“3.14 - RR 1.20”。仅刷新导航器不一定会替换已经运行的旧实例。
5. 保持原品种和 MagicNumber，并保留 MQL5\Files\PS_RR 与 PSRR_Settings。它们存有已有持仓的原始1R、执行进度及方案，不能删掉重置。

使用方法
图上每个持仓 TP 会显示：持仓编号 / TP序号 / R / 价格 / 平仓比例 / BE。
打开“分仓止盈” → “选择 / 下一持仓”，确认编号，修改尚未触发的目标后点“应用到该持仓”。
已触发行锁定；百分比始终按初始手数、合计100%。修改最终TP后留意“TP待同步 / TP已同步”。
“新仓方案”只影响之后的新仓，不覆盖现有持仓。
有未保存草稿时，先保存或撤销，再切换持仓。
目标水平线用于显示，请通过面板改目标；当前不支持直接拖动目标线。

兼容与测试
RR 1.10 的现有多目标持仓可编辑，RR 1.01 的旧两阶段持仓只读。
没有RR持仓记录的旧仓不会自动接管。
